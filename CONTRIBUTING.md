# Feedback / Contributing

This repository primarily seeks criticism and literature connections.

Useful feedback includes:
- Known literature that already explains these observations.
- Methodological problems in PCB-1 or the longitudinal interpretation.
- Alternative explanations for the local-smoothness/global-trajectory divergence.
- Better designs for testing online calibration without rewarding sycophancy.
- Reproducibility concerns.

Please distinguish evidence from speculation. Null/negative results should not be reinterpreted as hidden positive findings.
