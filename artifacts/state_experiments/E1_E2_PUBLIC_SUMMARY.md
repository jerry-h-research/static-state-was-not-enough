# E1/E2 — Public State-Experiment Summary

## E1/E1P
Rich-state and exploration-aware compression produced measurably different representations under near byte parity (reported byte ratio ~1.023236).

**Supported:** representation separation.  
**Not established:** downstream utility advantage.

## E2
Compact rich state, exploration-aware state, and full trajectory all produced high-quality continuation under a ceiling-limited blind evaluation.

- Exploration-aware > ordinary rich state: not supported.
- Full trajectory > compact rich state: not supported.
- Compact rich state can support high-quality continuation: supported in this probe.

The experiment therefore weakened the idea that more trajectory/state detail automatically yields better continuation.
